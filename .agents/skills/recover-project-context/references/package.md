# 包的来源与预算

生成器只读取六个约定文件：AGENTS.md、docs/project/brief.md、decisions.md、tasks.json、acceptance.md、README.md，以及当前Git分支、HEAD、porcelain工作区状态。包预算优先给规则、brief、决策与任务，较长README后收录。根项目入口转发到skill脚本，防止两套序列化规则。

交接不同目录的项目时，重复 `--source` 选择仓库内相对.md/.json/.txt文件，替换默认列表；不会暗中混入游造工作台的决策。私有/env路径、仓库外路径、符号链接与大文件仍被排除。明确指定来源文件名也会出现在包中，分享前核对文件名是否适合公开。

每个文件带来源路径和「工作区快照，尚未独立复核」状态。Git命令失败不会猜分支或提交。无提交仓库的HEAD仍标不可读取。任务JSON无效会带错误说明并保留原文，不能静默解析成空任务。

单个来源上限12000 bytes，总包默认20000 UTF-8 bytes。包预算不足时保留遗漏说明与恢复动作，并标记被截断的来源。需完整源代码时按路径读取，而不是增大聊天摘要到无限。

白名单和简单脱敏不能替代人工分享审查。自由文本可能含未识别个人信息；不复制私人历史，输出到临时目录后检查再交接。Git远程URL不会读入包。
