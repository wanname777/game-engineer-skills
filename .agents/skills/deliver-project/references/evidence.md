# 验收证据

| 类型 | 能说明什么 | 不能推断什么 |
| --- | --- | --- |
| 计划 | 将执行的步骤 | 已通过 |
| 人工记录 | 记录者执行过的步骤和观察 | 自动测试、CI或他人设备通过 |
| 命令日志 | 本次命令与退出状态 | 未执行的浏览器行为 |
| 浏览器行为 | 真实输入/反馈/刷新与可定位结果 | 未验证的线上或跨设备行为 |
| GitHub检查 | 当前commit关联的检查状态 | 工作区其他改动或部署成功 |
| 渲染产物 | 实际生成文件、时长与格式 | 尚未渲染版本的效果 |

每条任务完成记录包含来源路径或网址、命令/步骤、执行时点、结果、相关提交（如有）和限制。里程碑是满足依赖和验收的任务集合，不是任意绿色标签。

不预填成功。网络不可达、凭据缺失、检查未启动时记录实际阻塞，继续不依赖该项的工作。
