# 方案比较

| 维度 | 需要读取的证据 | 取舍 |
| --- | --- | --- |
| 已有工程 | 锁文件、核心源码、ADR | 复用收益、迁移成本、当前缺口 |
| 维护 | 维护者数量、升级/备份能力 | 单人避免不必要服务，团队也需明确责任 |
| 地区 | 目标地区访问实测、官方区域资料 | 地区不支持时属于硬约束 |
| 预算 | 官方价格与预算上限 | 标记核验时间，不承诺长期免费 |
| 密钥 | 调用方、权限范围 | 前端构建包不保存私密密钥 |
| 数据 | 本机/共享、刷新与重启结果 | 存在网址不等于数据已持久化 |
| 部署 | 构建、托管、回滚和监控条件 | 本地预览和线上交付分开 |

最多三项候选。先排除不满足硬约束的方案，再比较长期维护成本。为了保留可逆性，记录「出现什么需求时重新选择」而不是承诺永不迁移。
