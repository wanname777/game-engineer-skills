# ADR-001 — 星港快递首版技术

状态：原创示例方案，尚未部署。
来源：demos/project/brief.md、decisions.md。

## 约束

个人维护、中国大陆玩家、优先控制持续成本、无需私密服务端密钥、首版本机数据、静态网页入口。

## 比较与采用

| 路线 | 维护/成本 | 地区与权限 | 首版适配 |
| --- | --- | --- | --- |
| React + Vite静态网页 | 构建与托管简单，具体费用待核验 | 选择目标地区可访问的托管 | 当前优先 |
| React + Node API + PostgreSQL | 增加服务、备份、权限与持续计费 | 密钥可留服务端；目标地区部署待验证 | 共享需求出现时复议 |
| 网页 + 托管后端 | 减少运维但有规则配置与供应商迁移成本 | 先实测地区访问、权限与条款 | 当前地区条件未核验 |

采用静态网页，理由是当前首版不需要跨设备数据与私密调用。不能把任何私密密钥放入前端包。出现账号/共享进度时另立ADR，执行两设备写入读取、刷新与权限测试。
