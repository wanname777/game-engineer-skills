# 方法与原创边界

「月面花园 / Lunar Garden」的故事、构图、月球、温室、种子、植物、几何插画代码和解析合成音轨均在本临时目录原创实现。

采用项目内 create-motion-showreel skill 的 brief → 三张风格帧 → 单一绝对时间函数 → 交互预览 → Playwright 逐帧截图 → FFmpeg 编码与检查流程。该工作流的方法来源为 code秘密花园（ConardLi）的 garden-skills 固定版本 `08150e750bdc8c8dc452fb43c8ef5221b71c4308`，以及项目记录的局部视频片段。来源：[原始仓库](https://github.com/ConardLi/garden-skills)、[视频](https://www.bilibili.com/video/BV1f94c6uEr3/)。未完整观看或转录该视频；未复制原作品画面、音乐或字幕。

本地复用当前项目已安装的 Vite、Playwright 和 FFmpeg 依赖；没有修改当前项目或调用云端服务。

证据等级：skill与渲染契约是已读取的一手项目规范；本片的验证以运行日志、编码文件、像素哈希和实际查看为证据。音频指标不等同于实际听感。
