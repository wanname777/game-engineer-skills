# 离线2D关卡拼装工具 — PRD

状态：规划草案；2026-11-13。来源：raw-input.md。未实施、未执行工具验收。

## 目标与对象

交付类型：桌面优先的离线关卡创作工具，包含最小可玩预览；它不是一款完整发行游戏。

个人创作者在没有互联网的桌面环境中把地块拼成一个关卡，立即试走，保存后刷新继续，再把 JSON 文件交给使用同版本工具的朋友重载。两周由一名维护者完成首版闭环。

已确认：离线运行、2D、放地块、一键预览、JSON保存、刷新恢复、可重新载入的导出、个人维护、两周、桌面优先、无账号/云服务/排行榜、文件分享。

## 首版完整路径

首次准备好离线包及 Node 环境 → 启动固定本机地址 → 打开空白关卡 → 选择地块并点击格子放置/覆盖 → 橡皮擦删除 → 放起点与终点 → 一键预览 → 用方向键试走并碰墙/到达终点 → 返回编辑 → 保存本机 → 刷新页面恢复最后一次成功保存 → 导出 JSON → 在独立浏览器会话或朋友设备打开同版本工具 → 导入该文件 → 验证相同地块/起终点 → 预览 → 保存、刷新、再次导出。

“保存本机”把关卡序列化为 JSON 写入此浏览器存储；“导出 JSON”把当前关卡下载为独立文件。两者使用同一数据格式。导出不冒充浏览器保存成功。未保存修改刷新会恢复上次成功保存的关卡，界面必须明确提示有未保存修改。

## 首版范围

| 项目 | 计划行为 | 约束 |
| --- | --- | --- |
| 地块编辑 | 选择地面/墙，单击网格放置、覆盖；橡皮擦改为空格 | 默认24×16格、单层，无自由变形或旋转 |
| 标记 | 放置单一起点/终点，再放时移动标记 | 必须不同且位于地面格；删地面后清掉对应标记并显示提示 |
| 预览 | 一键用当前未保存关卡建立独立预览快照；四向逐格移动、墙/空格阻挡、到达终点有反馈 | 假设为俯视步行验证，不做平台跳跃、敌人、物理引擎或完整关卡游戏 |
| 返回编辑 | 退出预览回到编辑状态 | 预览运行态不能改写关卡或已保存 JSON |
| 保存/恢复 | 显式保存为JSON到 localStorage；刷新或重开同浏览器同地址恢复最近成功保存 | 不要求自动保存、版本库或多标签同步 |
| 文件 | 导出当前有效JSON；选择本地JSON导入；同版本可重复导入/导出 | 文件选择与 Blob 下载；不依赖原生文件系统授权 |
| 离线 | 断开外网后冷启动、刷新、编辑、预览、保存、导入、导出 | 首次安装依赖与浏览器并不保证无需联网；离线交付包须包含所有运行资源 |
| 桌面操作 | 1440×900与1280×720；键盘可选地块、移动网格焦点、放置、保存与进入/退出预览 | 非支持的窄屏显示桌面提示；手机完整编辑不在首版门槛 |

不做：账号、云存储、排行榜、实时协作、自动跨设备同步、在线素材市场、自定义资产导入、多层/超大地图、撤销历史、多关卡管理、移动端完整工具、原生安装签名/商店上架、动画发布片、线上托管。原创地块用简单色块/矢量图，避免额外素材授权与下载依赖。

## 数据与失败行为

规范字段见 ADR-001，手工样本见 samples/level-v1.json。默认24×16，导入接受1到64的整数宽高，最多4096格；格式版本1，地块仅0空/1地面/2墙；名称1到80字符，文件读取前限制256KiB。编辑器默认不提供尺寸变更UI；合法非默认尺寸导入后允许画布内部滚动。

数据有效性与可预览性分开：没有起终点的未完成关卡仍可保存/导出；预览必须有有效且不同的起终点，失败时明确定位缺项并留在编辑。导入尺寸/地块/标记/版本无效或文件太大时拒绝整份输入，当前关卡与保存数据保持不变。

导入成功先作为未保存的编辑关卡；用户点保存才替换浏览器恢复点。保存空间不足/被禁用时保留当前画面与可导出数据，保留未保存标记并提示失败；不能显示“已保存”。损坏的本地JSON不静默覆写：启动新编辑草稿，保留原存储键供导出诊断或显式重置，告知恢复失败。没有联系方式或密钥字段。

## 成功标准与真实验收计划

状态：全部尚未执行。可操作细节见 acceptance.md，证据须包含实际设备、版本、时间、命令/步骤、结果与输出文件。

1. 在桌面放地面、墙、起终点，预览能走在地面上、被墙和空格阻挡、到终点有反馈；退出后编辑数据相同。
2. 保存后修改但不保存再刷新，严格恢复最后成功保存的JSON；浏览器关闭重开同一地址也恢复。UI提示与实际数据一致。
3. 下载文件在全新会话导入后地块/标记/名称一致，再导出解析后结构等价；导入错误文件不破坏当前编辑/保存。
4. 切断外网并关闭重开本机服务和浏览器，完整执行上述路径，没有外部资源请求失败造成的核心缺失。
5. 朋友设备装有同版本工具和所需运行环境时可离线导入同一文件；未实际执行第二设备前只记录“独立会话通过”。
6. 当前提交的本机检查通过并有真实浏览器记录，才关闭对应任务。CI/部署不能从本机结果推出。
